# Alternative Audio Transcripts (FR)

Objectif: avoir 2-3 variantes par situation pour ne pas rejouer toujours le meme audio.

## Naming conseille

Garde l'ID logique tel qu'il est utilise dans le code (ex: `Day-vote/Day-vote-tie`) et ajoute des variantes suffixees:

- `Day-vote/Day-vote-tie__01.mp3` (ta version actuelle)
- `Day-vote/Day-vote-tie__02.mp3`
- `Day-vote/Day-vote-tie__03.mp3`

Pareil pour les transcripts:

- `Day-vote/Day-vote-tie__01.txt`
- `Day-vote/Day-vote-tie__02.txt`
- `Day-vote/Day-vote-tie__03.txt`

Ensuite, dans le code, tu joues au hasard une variante existante et tu retombes sur `__01` si `__02/__03` n'existent pas.

---
